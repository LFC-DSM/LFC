# LFC 화면 퍼블리싱

화이트와 비색을 사용한 React 18 + TypeScript 반응형 퍼블리싱입니다. 저장소 루트에서 `pnpm --filter frontend dev`로 실행합니다. 화면은 쿼리 파라미터로 구분합니다. Google Fonts에 연결할 수 없는 환경에서는 시스템 글꼴을 사용합니다.

## 화면 목록

- `?`: 1일차 메인
- `?day=2`: 2일차 메인
- `?day=3`: 3일차 메인
- `?page=home-guest`: 비로그인 헤더
- `?page=vote`: 주제 투표 (후보 3개)
- `?page=topic&id=0`: 주제 상세 (id 0~2)
- `?page=bet`: 진영 선택 및 베팅
- `?page=prompt`: 진영별 공동 문서, 우측 실시간 채팅
- `?page=debate`: AI 토론 및 목차, 반응
- `?page=archive`: 지난 토론 목록
- `?page=replay`: 토론 다시 보기
- `?page=shop`: 상점
- `?page=mypage`: 계정, 비밀번호, 재화, 테마, 탈퇴
- `?page=login`: 로그인
- `?page=signup`: 이메일 인증 회원가입

## 서비스 연결 시

현재 코드는 디자인 전달용입니다. 계정, 날짜, 이름, 잔액, 토론 내용, 결과와 수치는 예시 데이터입니다. 날짜에 따른 메인 화면은 실제 서비스에서 계산한 일차를 전달해 렌더링하도록 연결하세요. 디자인 확인용 day 파라미터만 제공하며 모든 화면 상단의 DAY 1·2·3 메뉴로 각 일차를 자유롭게 이동할 수 있습니다.

TK는 베팅 전용, CRD는 상점 전용입니다. 프롬프트 화면은 베팅한 진영 하나만 표시합니다. 반대 진영 문서는 서버 권한으로 반드시 접근을 제한해야 합니다.

페이지 링크 이동과 토론 목차 사이드바 펼침·접기, 목차 앵커 이동만 구현했습니다. 상점 검색과 분류 버튼은 디자인만 존재합니다. 구매·베팅·인증·투표·전송·저장·이모지 반응·출석·테마 변경·탈퇴·실시간 공동 편집·TTS는 UI만 존재하며 서비스 동작은 구현하지 않았습니다. 문서 본문은 정적 React JSX 퍼블리싱이며 실제 편집기 연결 지점은 `.paper`입니다. 상단 강조 채팅은 구매 아이템 사용 시 표시되는 디자인 예시입니다.

Emotion 기반입니다. 공통 색상과 리셋은 design/GlobalStyles.tsx, 반응형 화면 스타일은 design/DesignSurface.tsx에서 관리합니다. 각 화면의 세부 배치는 Emotion css prop을 사용합니다. 720px 이하 모바일, 1050px 이하 태블릿 레이아웃을 포함합니다.

댓글과 수정 제안 UI는 제거했습니다. 프롬프트 화면은 문서와 실시간 채팅의 2열 구성입니다. 화이트·비색 기반 네오브루탈리즘 스타일입니다. 굵은 테두리와 단단한 그림자, 평면 색상으로 시각적 재미를 더했습니다. 베팅 재화는 TK, 상점 재화는 CRD입니다.

첫 접속은 로그인 화면입니다. 로그인 링크는 ?page=home으로, 회원가입 링크는 ?page=signup으로 이동합니다. 회원가입 완료 UI는 로그인 화면으로 돌아갑니다. 실제 인증·검증 없이 화면만 이동하는 퍼블리싱입니다. 로그인·회원가입에서는 일차 메뉴를 표시하지 않습니다. DAY 1은 후보 중심, DAY 2는 예시 TK 베팅 현황, DAY 3은 토론 입장 중심이며 메인 배너는 제거했습니다.
